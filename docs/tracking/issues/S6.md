## Acceptance
- Batch membership is explicit from `batch_id`; invalid explicit batch/content IDs return HTTP 404 instead of falling back to another entity.
- Organic/Paid metric context is visible and separate; primary metric fields including AWT/WFV remain unavailable when unavailable, never converted to zero.

- Acquisition state comes from latest canonical `acquisition_run`; processing state/error remains separate from overall runtime job state.
- Evidence availability requires filesystem authorization/readability; missing frame/audio renders unavailable and media load errors have a visible fallback.
- Deep links, reload, Back/Forward, batch changes, abort/stale response handling, and selection reset are implemented without adding routing dependencies.
- Empty, error, synthetic-fixture, unavailable-media, keyboard-selectable batch/content controls, and mobile layout states are visible.
