# S8 — Evidence and hypothesis

## Scope
Create provenance-linked evidence and hypotheses from comparison results, transcript segments, frames, features, and metric snapshots.

## Status
Blocked by S4, S5, and S7.

## Acceptance
- Evidence layers remain OBSERVED/DERIVED/EXTRACTED/INFERRED.
- Every hypothesis cites evidence.
- Source references are immutable and exact.
- Deterministic confidence/data-quality caps override LLM output.
- SUSPECT metrics cannot support strong hypotheses.

## Verification
Database and unit tests for missing evidence, invalid source, low-confidence caps, and source-layer separation.

## Dependencies
S4, S5, S7
