# S3 — Actual media processing and temporal evidence

## Scope
Implement one processing path for acquired media: ffprobe facts, audio extraction, faster-whisper transcript segments, hook/representative frames, per-second frame inventory, and product-entry anchors.

## Status
Ready. Do not treat the live spike as persistent worker implementation.

## Acceptance
- Processing consumes normalized acquisition output, not provider payload shape.
- Temporary MP4 is deleted after derivatives and failure cleanup is safe.
- OBSERVED ffprobe facts remain separate from EXTRACTED evidence.
- Transcript timestamps are ordered and non-overlapping.
- Frames and product-entry anchors retain timestamps and source references.
- AWT is temporal context, never retention or causal proof.

## Verification
Add focused deterministic tests with fake media/tool runners; run actual-media smoke on a controlled fixture. Record artifact paths outside Git where needed.
